## OCR 专项结果

先导 4 张字段准确率 56.00%，字段值召回率约 57.69%，取自用户报告。正式 36 张合成卡的对应值为 51.5267% 和 52.3985%。F31 无文字，计入评分。独立 `testCaptureFormalOCR()` 已输出含 36 条记录的附件，但因 F31 触发失败断言，专项 XCTest 结果为 FAIL。该失败不替代 T20 的交互验收，也不用于推断常规回归结果。[OCR 评估与证据](12_week6_ocr_evaluation.md)

## 测试执行规则
1. 在复刻App上实际运行才可以将 `NOT_RUN` 改成 `PASS`。
2. 失败必须保留输入、期望、实际、日志、修复Prompt ID及回归结果。
3. 每次实现新模块运行相应单元测试与全部既有回归测试。
4. UI Golden Test以我们采集的参考截图做行为/位置比较，但**不要在最终 App 中直接使用参考 App 截图或版权资源**。
