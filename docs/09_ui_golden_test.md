## 人工补拍顺序与检查清单

1. 用隔离的空数据环境拍 G01，记录是否为 Release/Debug。不要清除已有业务记录。拍 G05 来源与相册取消，然后用同一张虚构名片完成 G06 → G07 → G08，留存确认前、确认后及保存反馈。
2. 保存后拍 G02 和 G09，确认列表计数、姓名/公司/职位、联系方式和长备注。打开 G11 两张图，确认比例和返回位置。用长网址、长地址、多电话/邮箱检查滚动和字段可读性。
3. 走 G10 的编辑保存及取消各一次。用大字号和键盘检查表单底部、电话及邮箱 44 pt 删除入口、取消/确认是否仍可达。
4. 拍 G03 的空查询、命中、无结果与退出。拍 G04 的标签空状态、重复和删除确认，再检查标签与搜索组合。冷启动后核对修改字段、备注、标签及图片，供 T18 取证。
5. 拍 G12 分享和取消，另记录 VCF 接收端结果。仅以虚构号码和邮箱检查系统提示，停在拨号或邮件确认之前。
6. 单独补异常状态。拍加载、OCR 处理中、无文字、无候选和校正失败、保存失败、删除确认及权限拒绝。无法稳定触发的失败保持 NOT_RUN 并注明限制。真机相机授权与实际拍摄单独取证。
7. 拍一轮相同外观的双方基线，再对 CardSlice 补大字号和键盘。检查标题层级、对齐、间距、留白、按钮样式及覆盖内容。系统界面语言与原生控件外观按环境记录。

### 剩余问题分流

- **必须修复**。本轮未确认有阻断 Week 6 开始的 UI 缺陷。原基线的固定缩略图占位和普通路径开发标记已定点处理，扫描名称、字段标签、按钮和识别结果分组已落实。仍出现的开发菜单标记位于 DEBUG 入口，测试数据源提示限测试情境。
- **人工验收**。实测长字段、长 OCR 原文展开、大字号与键盘下的底部按钮和取消弹窗。源码可见表单滚动及安全区域避让，实际触达尚未取证。用同一记录核验保存回列表、编辑回详情、退出丢弃以及失败重试，若复现阻断再定点修复。当前 G08 未提供表单内名片预览，已有识别原文及详情双图路径，不列为课程阻断。
- **证据与设备**。优先归档上表状态，登记样本、版本、设备、系统、外观、字号、操作步骤和实际结果。相机权限与真拍须真机，模拟器无相机提示仅证明回退路径。VCF 需真实接收端验字段，截图显示分享面板不足以判通过。
- **可选视觉**。参考 CamCard 英文与复刻简体中文属于已知环境差异。配色、圆角及装饰间距留作观察，不开额外修复任务。参考未观察状态继续标记 [OPEN]。
