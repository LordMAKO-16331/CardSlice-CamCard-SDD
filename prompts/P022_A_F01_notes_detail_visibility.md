# P022-A-F01 — 修复名片详情页备注不可见问题

## 一、问题背景

P022-A 已实现备注新增、编辑与保存。

用户在 iPhone 17 模拟器中发现：

- 进入已保存名片详情页时，看不到备注。
- 必须点击「编辑」才能看到备注内容。
- 备注编辑及保留操作正常。
- 搜索功能正常，但关键词高亮等 UI 问题留到后续 UI Golden Test。

本轮只检查和修复备注在详情页的展示，不修改搜索功能。

## 四、修复要求

1. 已保存名片存在非空备注时，在详情页显示备注内容。
2. 备注为空时允许不显示备注区域。
3. 中文、英文和多行备注应完整展示。
4. 不需要进入编辑页面才能查看备注。
5. 备注更新后，详情页应同步显示最新值。
6. 不得修改备注的数据库保存逻辑。
7. 不得影响姓名、公司、电话、邮箱等已有字段。
8. 不得影响编辑、删除和导航功能。
9. 不进行大规模 UI 重构。
