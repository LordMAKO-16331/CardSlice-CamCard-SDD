# P025-B2-F01 — Week 5：修复名片详情页基本信息语义区分

## 一、问题

P025-B2 的详情页布局优化后，姓名、公司和职位被直接上下排列，没有明确字段标签。

例如：

玛恩纳\
卡西米尔\
近卫-解放者

用户无法直观区分后两个字段的含义。

本轮只修复此问题，不进行其他 UI 优化。
