# P021-F01A — 动态字段管理完整性审查

## 一、背景

CamCard SDD iOS 项目的 P021 搜索功能已通过用户手动验证。

目前发现已保存名片的编辑界面存在以下问题：

1. 点击「新增电话」可以添加电话号码，但没有明显的删除方式。
2. 点击「新增邮箱」可以添加邮箱地址，同样没有明显的删除方式。
3. 其他动态添加字段尚未全面检查。
4. 人工校正页面是否存在相同问题尚不确定。

本轮目标不是仅修复电话，而是审查所有动态字段操作是否完整。

## 三、审查范围

只读检查与以下功能相关的实际代码：

- 已保存名片编辑。
- OCR 后人工校正。
- 编辑草稿与状态管理。
- 电话及邮箱列表组件。
- 所有含有「新增」「添加」等动态字段操作的表单。
- 对应的已有单元测试。

重点检查：

1. 是否支持新增。
2. 是否支持修改。
3. 是否支持删除指定项目。
4. 删除入口是否在 UI 中真实可访问。
5. 删除中间项目后，数组索引及 UI 绑定是否正确。
6. 删除最后一项后能否保持空集合。
7. 新增空项目是否会被错误保存。
8. 保存后新增、修改、删除是否持久化。
9. 取消编辑是否不会污染已保存数据。
10. 人工校正与已保存名片编辑是否存在能力不一致。

不要只搜索按钮文字；应检查实际状态管理和数据流。

## 四、输出审查报告

请列出发现的每一个问题，包含：

- 所在文件和具体组件。
- 涉及的字段。
- 当前已经实现的操作。
- 缺少的操作或潜在缺陷。
- 问题的严重程度。
- 建议的最小修复方式。
- 所需修改文件范围。
- 现有测试是否覆盖此问题。

最后给出一个统一修复方案，优先复用现有组件，避免重复开发不同的电话和邮箱编辑逻辑。
