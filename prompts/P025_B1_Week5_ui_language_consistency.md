## 四、统一原则

本轮使用简体中文作为自建业务界面的主要语言。

统一常见术语：

- CardHolder → 名片夹
- Search → 搜索
- Add Note → 添加备注
- Edit → 编辑
- Save → 保存
- Cancel → 取消
- Delete → 删除
- Tags → 标签
- Export Contact → 导出联系人
- Retake → 重拍
- Import from Album → 从相册导入

上述仅为命名参考，应根据实际页面语义避免错误翻译。

OCR、VCF、Email 等技术缩写可保留。

要求：

1. 同一操作在不同页面使用一致的文字。
2. 不混用含义相同的中文和英文按钮。
3. 错误提示应让普通用户理解发生了什么。
4. 不修改用户自己输入的姓名、公司、备注和标签。
5. 不翻译 OCR 原始文本。
6. 不翻译测试数据与持久化数据。
7. 不修改导出 VCF 的字段名及协议内容。
8. 不强行修改 iOS 系统组件的系统语言。
9. 不为了翻译文案添加新的功能或页面。

## 五、重要限制

本轮只修改 UI 文案及直接相关的无障碍标签。

不得修改：

- BusinessCardRecord
- Repository
- SwiftData Schema
- OCR 和字段解析
- 相机采集逻辑
- 搜索匹配算法
- 标签与备注的数据逻辑
- VCF 导出服务
- 页面导航结构

不得进行大规模 SwiftUI 布局重构。

不得改变已有按钮的执行动作。

如果已有测试断言依赖旧 UI 文案，只允许同步调整相关测试断言，不得降低测试覆盖程度。
